# Schneider Electric Conext firmware archive

**Installed now (as of 2026-10-11):**
- XW Pro 6848 NA (865-6848-21), units 10 and 12: **2.04.00 build 29**

Schneider's XW Pro product page warns that some generators hum or buzz excessively on v2.04. For sites that use a generator, it recommends staying on (or going back to) **v1.11.01 Build 0049**, which is archived here too.

Scripted access to the `www.se.com` document pages is blocked (HTTP 403), so the files were fetched from the URL each page links to. The page is listed as the source and the direct file URL is listed under it.

## Notes and gaps

- **No XW Pro 6848 NA release newer than 2.04.00 BN0029 was found** on se.com or solar.se.com (checked 2026-10-11). Schneider's notice that a fix for the v2.04 generator issue was "coming shortly" has no matching release in the published downloads. The XW Pro product page's own Documents list could not be read because it returns 403 to automated requests, so check it in a browser to be sure.
- The v2.04 package on se.com has no separate release-notes document. Its release notes are inside the zip.
- The v1.11.01 BN0049 document is published as three separate files and has no single named zip, so each file was archived under its original name.
- **Conext Gateway:** the se.com download library serves v1.18 **BN33**. The installed **BN41** build comes from the solar.se.com Gateway product page. Both are archived. No Gateway firmware newer than v1.18 was found. That page also lists older builds (v1.14, v1.16 BN004, v1.17 BN79), which were not archived.
- **XW+ 5548:** only the 120/240V package (865-5548-01) was archived. A 120V package (v2.07 BN4) also exists: https://solar.se.com/us/wp-content/uploads/sites/7/2021/11/conext-xw-5548-120v-firmware-ver-2-07-bn-4.zip
- No file is over 100 MB, so nothing was skipped and no LFS is used.
